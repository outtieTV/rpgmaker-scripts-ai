# rpgmaker-scripts
RPG Maker Scripts, usually MZ.<br />
These were written by outtieTV, Google Gemini, Duck AI, and ChatGPT.<br />
<br />
BuildAndDecorate_MZ_v1.js<br />
RMMZ plugin to allow players to place objects on the map and the objects stay in the same location. Save persistent.<br />
<br />
ChestSystem_MZ_v1.js<br />
RMMZ plugin to extend player inventory with in-world chests. Save persistent.<br />
<br />
CustomItems_MZ.js<br />
RMMZ plugin to allow for images to be used as in-game items.<br />
<br />
CustomShops_MZ_v1.js<br />
RMMZ plugin to allow for limited quantity and unlimited quantity shops where the player can buy/sell items.<br />
<br />
FactionReputation_MZ_v1.js<br />
RMMZ plugin to add reputation per region/faction. Save persistent.<br />
<br />
FarmingSystem_MZ_v2.js<br />
RMMZ plugin to add farming on specific tile ids.<br />
<br />
FishingSystem_MZ_v1.js<br />
RMMZ plugin to add fishing with a fishing minigame and percentage chance of drops.<br />
<br />
GameTime_MZ_v1.js<br />
RMMZ plugin to add an in-game day/night cycle.<br />
<br />
GatheringSystem_MZ_v1.js<br />
RMMZ plugin to add a gathering profession.<br />
<br />
HPandEnergyOverlay_MZ_v1.js<br />
RMMZ plugin to add an HP and Energy overlay for the player, not just HP and Stamina.<br />
<br />
HotbarPlugin_MZ_v1.js<br />
RMMZ plugin to add a hotbar with icons and the player can set active slot with 0-9 on the keyboard.<br />
<br />
HotkeyCommander_MZ_v1.js<br />
RMMZ plugin to let the developer bind plugin commands to a specific hotkey for the player.<br />
<br />
Mailbox_MZ_v2.js<br />
RMMZ plugin to add a simple mailbox system for NPC to Player messages. Allows for items and gold to be added to a message. Save persistent.<br />
<br />
PicAnchor_MZ_v1.js<br />
RMMZ plugin that allows pictures to be anchored on the map to mimic objects.<br />
<br />
SQL_MZ_v1.js<br />
RMMZ plugin that allows the developer to connect the player to a SQLite/MS SQL/MySQL/PostgreSQL server.<br />
<br />
SimpleGauge_MZ_v1.js<br />
RMMZ plugin to test if gauge overlays work.<br />
<br />
StopMove_MZ_v1.js<br />
RMMZ plugin that prevents player from moving on specific tiles, to make them "solid".<br />
<br />
WeatherSystem_MZ_v1.js<br />
RMMZ plugin that adds weather to maps.<br />
<br />
combine-sheet.py<br />
RMMZ utility for spritesheets.<br />
<br />
divide-sheet.py<br />
RMMZ utility for spritesheets.<br />
