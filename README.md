# rpgmaker-scripts
RPG Maker Scripts, usually MZ.<br />
<br />
divide-sheet.py<br />
Python 3.x<br />
Takes in a spritesheet and divides it into evenly shaped PNG files.<br />
<br />
combine-sheet.py<br />
Python 3.x<br />
Takes in a folder of evenly shaped PNG files and outputs a combined spritesheet.<br />
<br />
GameTime_MZ_v1.js<br />
RPG Maker MZ Plugin to count in-game seconds, minutes, hours, days, months, seasons, and years. Can scale to make days faster.<br />
<br />
FarmingSystem_MZ_v1.js and FishingSystem_MZ_v1.js<br />
RMMZ plugins for professions.<br />
<br />
ChestSystem_MZ_v1.js<br />
RMMZ plugin to extend player inventory.<br />
<br />
HotbarPlugin_MZ_v1.js<br />
RMMZ plugin to show important skills/etc in a hotbar.<br />
<br />
HotkeyCommander_MZ_v1.js<br />
RMMZ plugin to bind plugin commands to keyboard keys.<br />
<br />
PicAnchor_MZ_v1.js<br />
RMMZ plugin to keep a picture in the "same" location on the map.<br />
<br />
StopMove_MZ_v1.js<br />
RMMZ plugin to stop the player from passing onto certain region ids.<br />
<br />
HPandEnergyOverlay_MZ_v1.js<br />
RMMZ plugin for Hitpoints and a new Energy Meter.<br />
<br />
WeatherSystem_MZ_v1.js<br />
RMMZ plugin to control the weather.<br />
BuildAndDecorate_MZ_v1.js<br />
RMMZ plugin to allow players to place objects on the map.
